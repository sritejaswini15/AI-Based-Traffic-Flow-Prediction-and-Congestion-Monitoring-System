What you get

Forecasts with a range

Every forecast comes with an 80% range. The range was measured on days the model never trained on, so it shows how far off forecasts usually are.

Congestion at a glance

Each junction is rated low, moderate or heavy against its own history, now and for the next hour. Spot the busy ones before they jam.

Accuracy you can check

The model page compares every horizon with simple baselines on held-out days. The dashboard tracks today's error as the day goes on.

How it works

  1. Recorded counts. 56 days of vehicle counts from six junctions, read every 5 minutes. Sensor outages are treated as missing, not as empty roads.
  2. A model per horizon. Gradient-boosted trees learn from the last few hours, the same time yesterday and the same time last week.
  3. An honest replay. There is no live feed, so the dashboard replays the final eight days, which were held out from training, in step with your clock.
